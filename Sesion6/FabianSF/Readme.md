## Nota Importante para Visualización en GitHub (Errores 'Invalid Notebook')

Si al visualizar este notebook en GitHub encuentra un error como `Invalid Notebook` o mensajes relacionados con `metadata.widgets`, por favor, tenga en cuenta que **esto no indica un error en el contenido ni en la ejecución del notebook**. Este mensaje es una limitación conocida del renderizador de archivos `.ipynb` de GitHub, que en ocasiones no soporta adecuadamente la metadata generada por interfaces interactivas como Gradio.

Le recomendamos encarecidamente abrir este notebook directamente en Google Colab. Al ejecutar las celdas en Colab, podrá interactuar con la interfaz de Gradio y observar todas las salidas y funcionalidades tal como fueron diseñadas y probadas.
